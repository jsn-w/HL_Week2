# fixitpen
I wanted to create a pen that can be used for different applications. In the design that I put together, I modeled a regular pen with the body, bottom and top attachments.
To add a different touch compared to regular pens, I added an attachment slot, where you are able to attach tools to the pen, making it multipurpose. One of my attachments was a hexagon slot to fit a screwdriver bit into on both ends, which makes it nice and convenient to have around.

## How I made this
- I used Fusion360 for modeling each part of the pen, assembling them together, and creating an animation to showcase the assembly of the entire pen.
- Pen body: I create a 11.5cm tall pen body to fit the pen ink and gel that I currently have. There are threads on the top and bottom to be able to connect to different components. There is also a slot on the side to see the pen ink level.
- Pen tip: this is a typical pen tip and has threads on the inside of it. I also added grooves to the edges to add a grip to the pen.
- Screw accessory: part that houses the component that I want to place in. It currently fits a hexagon assembly, but can be altered for different purposes.
- Screw cap: encloses the cap so that it looks like a regular pen when it is not in use.
